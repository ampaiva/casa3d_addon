# Casa 3D

Add-on do Home Assistant para abrir a planta interativa da casa como um painel próprio.

Esta versão inicial embala o editor de posições do Casa 3D. A ideia é tirar a dependência do servidor local e evoluir o projeto como uma aplicação completa dentro do Home Assistant.

## Visões planejadas

- Planta real da casa;
- mapa físico dos dispositivos;
- fios entre canais dos switches e lâmpadas/cargas;
- mapa Zigbee;
- mapa elétrico;
- mapa hidráulico.
